# The Wandering Museum — WebXR build

A hands-first WebXR experience for Meta Quest: a night river of paper lanterns, each carrying a Chinese artifact now held in a museum overseas.

**Open in the Meta Quest Browser:** https://yiwadeng.github.io/xr

Built with three.js and React Three Fiber. This repository contains the built static site only.
Entry for the Meta VR Start Developer Competition 2026.
